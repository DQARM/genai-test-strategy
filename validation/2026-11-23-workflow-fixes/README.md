工具 1.13.1 在 Linux、Python 3.12.14、Git 2.56.1 上通過 150 個專案工具測試與 9 個評測工具測試。本次新增 7 個回歸測試，涵蓋逐案審查、登錄並行寫入、就緒案例資料、設計模型與條款變動的回歸選案、乾淨工作樹補標籤及空白作答。未在原生 Windows 執行。

## 行為評測

15 個合成情境各由新的 Codex 工作階段執行一次。作答後逐條比對評分準則，57 項通過，0 項失敗。4 個有預設專案的情境另比對檔案與執行結果。各情境的一般結構檢查通過，建立新基線的檢查按預期阻擋。確切模型版本及取樣參數未揭露。本次使用同一環境，未執行實際產品或跨模型評測。

| 情境 | 核對範圍 |
|---|---|
| 01–04 | 未決邊界、衝突規格、操作介面缺漏、口頭需求 |
| 05–08 | 系統風險、第五答後產出、未知決策時間、案例斷言能否辨識錯誤 |
| 09–12 | 承接審查、產品與環境回報分流、設計及審查階段的來源權威 |
| 13–15 | 設計方法與案例覆蓋、版本與負載條件、介面與交付條款 |

[原始回覆、評分理由與檔案證據](behavior-evidence.zip) 包含輸入、技能及原始資料的指紋、15 份原始回覆、15 份逐項評分、4 份工作區擷取與最終統計。原始回覆中的暫存路徑保留作當次執行紀錄。合成專案的存檔內容在解壓目錄的 `artifacts/case-XX/files/`。

從儲存庫根目錄執行以下命令，可重新核對每項評分的逐字證據與檔案指紋，並比對評分統計。

```bash
run_dir=$(mktemp -d)
python3 -m zipfile -e validation/2026-11-23-workflow-fixes/behavior-evidence.zip "$run_dir"
python3 evals/evaluate.py score "$run_dir" > "$run_dir/replayed.json"
diff "$run_dir/score.json" "$run_dir/replayed.json"
```
